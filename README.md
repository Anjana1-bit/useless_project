## Project Description

Googlen't is a deliberately unhelpful desktop application that looks and behaves like a familiar Google-style ecosystem — until you actually try to use it.

It provides useless versions of everyday tools like search, email, passwords, and maps, turning simple tasks into increasingly ridiculous problems.

---

## The Problem (that doesn't exist)

Modern technology has become far too convenient.

People can search for information, send emails, create passwords, find directions, and even close applications without being unnecessarily frustrated.

Googlen't was created to solve this completely fictional problem.

---

## The Solution (that nobody asked for)

We built Googlen't — an application that takes perfectly normal digital services and makes them unnecessarily difficult.

Want to search something?

**Searchn't** will understand your question perfectly and then refuse to answer it.

Want to send an email?

**Gmailn't** will reject it because your message doesn't contain enough emotional context.

Need a password?

**Passwordn't** starts with normal requirements and slowly turns them into an impossible checklist.

Need directions?

**Mapsn't** confidently gives you increasingly questionable directions.

And when you finally want to escape the application...

**You can't.**
